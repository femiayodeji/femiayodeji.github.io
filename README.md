# oluwainstincts

> Personal portfolio and project showcase for Femi Ayodeji

## Overview
Oluwainstincts is a modern, responsive static website built with HTML, CSS, and JavaScript. It highlights engineering, AI, game development, and sustainability work by Femi Ayodeji.

## Features
- Clean, accessible, and mobile-friendly design
- Theme toggle (dark/light)
- Animated background and scroll reveal effects
- Sections for About, Skills, Experience, Projects, Sustainability, Education, and Contact

## Project Structure
- `index.html` – Main HTML file
- `styles.css` – All site styles
- `scripts.js` – All site JavaScript
- `.gitignore` – Files and folders to exclude from git
- `README.md` – Project documentation

## Getting Started

1. Clone the repository:
	```sh
	git clone https://github.com/femiayodeji/oluwainstincts.git
	```
2. Open `index.html` in your browser. No build step required.

## Customization
- Update content in `index.html` as needed
- Edit `styles.css` for custom styles
- Edit `scripts.js` for custom interactivity
